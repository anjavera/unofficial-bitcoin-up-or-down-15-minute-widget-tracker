# BTC15 Widget Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the UI-free core the widgets will share: window model, colour bands and themes, exact 24h history, live Polymarket feed, exchange-composite price proxy with measured error, and the absorbed `pm` CLI.

**Architecture:** Pure modules (`model`, `colors`, `theme`) with no I/O; I/O modules (`history`, `feed`, `proxy`, `calibration`, `client`) that take injected clients/fetchers so tests use fakes; a thin `cli`. Terminal widget, desktop window, signals and the desktop shortcut are separate later plans and are out of scope here.

**Tech Stack:** Python >=3.12, `polymarket-us` SDK, `python-dotenv`, stdlib `urllib`/`asyncio`/`json`, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-09-30-btc15-widget-design.md`

## Global Constraints

- Result rule: **Up if close >= open**; Polymarket "Yes" = Up; outcomePrices order is `[Yes, No]`.
- Slugs: event `btc-updown-15m-YYYY-MM-DD-HHMMz`, market `cpc-btc-updown-15m-YYYY-MM-DD-HHMMz`; all window times are UTC.
- Open = `assetPriceTerms.priceToBeat`, close = `assetPriceTerms.settlementPrice` (real BRTI, only present once settled).
- Result colours: **green = UP, red = DOWN**. Net-change colours: **positive = blue, negative = orange**, 9 steps by |net|: 0-10, 10-25, 25-50, 50-100, 100-200, 200-300, 300-400, 400-500, 500-1000 (capped at 1000+).
- Theme setting: `dark` / `light` / `system`, default `system`; persisted in a local config file.
- Proxy = mean of Coinbase, Kraken, Bitstamp, Gemini public quotes, displayed as "≈". **Proxy values never enter history.**
- Read-only everywhere: no order placement. Never print or commit `.env` or keys.
- Polymarket REST can trip Cloudflare 1015: retry with backoff and cache settled windows.
- Python >=3.12, `polymarket-us>=0.1.2`.

## Review Focus

1. A window whose market does not exist yet, or is live with no `settlementPrice`: must yield an unsettled `Window` (net/result `None`), never raise.
2. One failed or missing history window: must appear as a gap entry in place, never shift the 96-window strip.
3. Exchange quotes that fail, return `0`/negative, or sit >5% from the median: dropped; if none remain the composite is `None`, not `0`.
4. Net change exactly on a band edge (10, 25, ... 1000), exactly `0`, negative, or beyond 1000: deterministic band, capped at the last step.
5. Feed disconnect mid-window or missing credentials: feed reconnects without duplicating state; missing credentials raise one clear `RuntimeError`, not a `KeyError` trace.
